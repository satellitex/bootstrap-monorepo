# Refactorer Profile — 検出コマンド・必読ガイド・対象範囲

> この文書は refactorer agent が検出フェーズで Read する PJ 固有 profile である。検出フロー・観点分類・Issue 化の手順は書かない（`.claude/agents/refactorer.md` が正本）。
>
> 記入指示: bootstrap 時に、対象プロジェクトの言語スタックと `docs/styles/coding_guide/` の実際の構成に合わせて `TODO(...)` を埋める。`TODO(取得方法: ...)` は環境から取得して確認する値、`TODO(記入方法: ...)` はチームが決めて書く値である。言語・ガイドを追加/削除したら本表も同一 PR で更新する。
>
> 未記入の扱い: `TODO(` で始まる項目は、refactorer が未記入として読み飛ばし、完了報告に未記入の件数を載せる。埋めるまでは「共通（言語非依存）」の検査だけが有効になる。

## 検出コマンド表

`origin/main` 最新のコードに対して実行する。refactorer は HEAD が `origin/main` と異なるとき、`origin/main` を detach した一時 worktree のルートでコマンドを実行する。依存のインストールを要するコマンド（lint など）が worktree 内で動かない場合、refactorer は実行せず、完了報告にその旨を明記する。

ヒット = 即 Issue ではなく、`refactoring_guide.md` の検出基準と突き合わせて観点にグルーピングする材料とする。

### 共通（言語非依存・既定で有効）

lint の警告とエラーは、検証ゲートの `lint`（定義 → `docs/harness/skills/shared/verification-gates.md`）を実行し、出力の警告行・エラー行を一次シグナルとして集める。

```bash
# 放置マーカーの棚卸し（bootstrap 時に --include で PJ の対象拡張子へ絞り込む）
grep -rn 'TODO\|FIXME\|HACK' apps/ packages/
```

### コード量削減の観点（効いていない / 非推奨の残置 / 冗長）

`docs/styles/refactoring_guide.md` の「コード量削減の観点」の各行に対応する検出観点とコマンドである。参照が残っていて消しても振る舞いが変わらないコードが対象で、削減候補にする前に「削減候補の反証と公開面」の反証を確かめる。コマンドの `<...>` は検査ごとに置き換える。

| 分類         | 検出観点                                         | 検出コマンド                                                                                                                                                                    |
| ------------ | ------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 効いていない | 全呼び出し元が同じ値を渡している引数             | `git grep -n '<関数名>(' origin/main -- apps packages` の結果から、渡している値を集計する（機械集計できない言語は目視）                                                         |
| 効いていない | 誰も指定しないオプションと、その分岐             | `git grep -n '<オプション名>' origin/main` で、定義以外に指定箇所があるかを確認する                                                                                             |
| 効いていない | 読み取られない設定キー                           | TODO(取得方法: 設定スキーマのキーを列挙するコマンド。各キーを `git grep -n '<キー名>' origin/main` で読み取り箇所に照合する)                                                    |
| 効いていない | 使われない依存                                   | TODO(取得方法: 採用したスタックの未使用依存の検出コマンド。無ければ依存宣言の各パッケージ名を `git grep -n '<パッケージ名>' origin/main` で import 箇所に照合する)              |
| 効いていない | コメントアウトされたコード                       | `grep -rnE '^\s*(//\|#)\s*(const\|let\|var\|function\|class\|import\|export\|return\|if\|for)\b' apps/ packages/`（bootstrap 時に対象言語のコメントマーカーと構文語へ合わせる） |
| 効いていない | 常に同じ結果になる型ガード・条件分岐             | TODO(取得方法: 採用した lint ツールの「常に真または偽になる条件」を検出するルールの実行コマンド。有効設定は次節で確認する)                                                      |
| 非推奨の残置 | 呼び出し元が残る非推奨の別名                     | `grep -rnE '@deprecated\|deprecated' apps/ packages/` でマーカーを列挙し、各シンボルを `git grep -n '<シンボル名>' origin/main` で呼び出し元に照合する                          |
| 非推奨の残置 | 利用者がいなくなった互換レイヤ                   | `grep -rniE 'compat\|legacy\|shim' apps/ packages/` で候補を列挙し、互換対象の入力を渡す箇所の有無を確認する                                                                    |
| 非推奨の残置 | 全環境で同じ値の feature flag                    | TODO(取得方法: 環境ごとの設定ファイルのパスと、flag を列挙するコマンド。列挙した flag の値を環境間で比較する)                                                                   |
| 冗長         | 重複ロジック                                     | TODO(記入方法: 採用した重複検出ツールのコマンド。無ければ「重複ロジック」観点の検出方法に従い目視で確認する)                                                                    |
| 冗長         | 標準 API・導入済みの依存・共通モジュールの再実装 | コードを読んで判断する（機械的検出の対象外）                                                                                                                                    |
| 冗長         | 素通しの wrapper                                 | コードを読んで判断する。`git grep -n '<関数名>' origin/main` で呼び出し元が 1 経路だけかを補助確認する                                                                          |
| 冗長         | 型定義から導出できる型の手書き再定義             | コードを読んで判断する（機械的検出の対象外）                                                                                                                                    |

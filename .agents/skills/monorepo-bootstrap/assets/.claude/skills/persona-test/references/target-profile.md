# ペルソナによる利用テストの固有値（プロジェクト profile）

この文書は、`/persona-test` が使うプロジェクト固有値（対象のホスト、検証環境の入り方、アカウントの作り方、利用に要る権利の付与、送り先、ペルソナの既定の条件）の profile である。手順は書かない（正本は `docs/harness/skills/persona-test.md`、設定の形は `docs/harness/skills/persona-test/tools.md`）。

> 実環境で確かめた値だけを書く。秘密値そのものは書かず、置き場だけを書く。プロダクトに当てはまらない欄は「該当なし」と書く（`TODO(` が残る欄があると、S0 で止まる）。

## 対象と環境

使う区分の行だけを残す。本番は見るだけにし、登録や入力は検証環境で行う。本番の登録には人間しか入力できない資格情報（パスワード、メールの認証コードなど）が要り、本番のデータも変えないためである。

- パート A で本番のアプリへ進むボタンの行き先を控え、パート B は検証環境の同じパスとクエリから入る。クエリに本番のホストが入っている場合（戻り先の URL など）は、検証環境のホストに置き換える。
- 検証環境が本番より新しい内容で動いている場合（開発ブランチを配備している場合など）は、本番との違いに気づいたら、違いをそのまま記録する。

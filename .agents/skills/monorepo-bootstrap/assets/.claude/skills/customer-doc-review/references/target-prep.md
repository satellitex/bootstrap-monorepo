# 対象準備（customer-doc-review profile・記入用テンプレート）

この文書は `/customer-doc-review` の Step 1（ターゲット準備）を、プロジェクトの公開パイプラインに合わせて具体化する profile である。手順・観点・レポート構成は書かない（正本は `docs/harness/skills/customer-doc-review.md`）。公開区画の一覧と、区画ごとの顧客可視の本文ファイルの正本は `docs/CUSTOMER_PUBLISH_POLICY.md` §1 の区画表であり、本ファイルには複製しない。

**本ファイルは章構成だけの空テンプレートである。** bootstrap 時に各章を実プロジェクトの公開ビルドの内容で埋めるまで、`/customer-doc-review` は生成物から顧客可視テキストを作れない。未記入のまま実行しないこと。

## 注意（記入前に確認する）

公開区画によって、顧客が実際に見る本文の置かれるファイルが異なる。ビューアのシェル HTML と、ビューアが読み込む仕様・データファイルが別のとき、本文は後者にある。シェルだけを抽出すると主要な公開文面が監査から漏れ、サイレントな false negative になる。各章は、本文側のファイルを必ず対象に含める形で記入する。

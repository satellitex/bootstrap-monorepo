# conflict 解消・CI 修正の profile（プロジェクト固有値）

この文書は `/review-cycle` の conflict 解消（Step 2.3）と CI 失敗の修正（Step 2.5）が使う PJ 固有値を定義する profile である。判定表・解消手順・分類の規則は書かない（正本は `docs/harness/skills/review-cycle.md`）。

> 値は実環境で確認したものだけを記入する。`TODO(...)` が残る項目は未記入である。
> 該当しない節は「なし」と書くか、節ごと削除する（なしの節は判定表の対応する行を無効にする）。

## 更新手順

1. 生成物・連番ファイル・CI レビュー bot の構成を変更したら、本ファイルを同一 PR で更新する
2. 照会していない値を書かない
3. 判定表・解消手順の規則は本ファイルに書かない（正本の `docs/harness/skills/review-cycle.md` を更新する）

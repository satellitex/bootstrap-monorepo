# sync 系・レビュー系の共通フィルタ（CI ノイズの除外 + 退避先の既存性確認）

この文書は、定期検査とレビュー対応の手順が共通で使う 2 つの絞り込み手順（非アクションの CI ノイズの除外、違反の退避先の既存性確認）の正本である。bot のマーカー文字列などプロジェクト固有の値と、退避先を判定する規約の本体（`docs/styles/coding_guide/docs.md`）は書かない。

呼び出し側の skill 文書は、該当する Step で本ファイルを Read し、その手順に従う。skill 固有の差分だけを呼び出し側に残す。

## 1. 非アクションの CI ノイズを除外する

PR のコメント・レビュー本文のうち、次の 3 つは対応対象ではないため処理対象から除外する。

| 除外条件                                                                                      | 判定                                                                         |
| --------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------- |
| `<iac-tool>` の変更プレビュー等の機械生成コメント                                             | bot が固定の HTML コメントマーカーを付けている場合は、そのマーカーで判定する |
| CI レビュー bot の auto マーカー付きコメントで、本文が `LGTM` のみのもの                      | 対応対象から除外する。終了判定のシグナルとして保持するかは呼び出し側が定める |
| check status / workflow log の通知のみで、file / line / fix suggestion を含まない CI イベント | 通知の形式で判定する                                                         |

- 除外したコメントの本文は、後続の手順（subagent を含む）へ渡さず、会話へ貼り付けない。長文の本文が文脈を占有し、対応すべき指摘を埋もれさせるためである。記録するのは「CI ノイズ」としての件数だけにする。
- 機械生成コメントの詳細確認が必要なときは、コメント本文ではなく artifact / workflow run の URL を開き、必要な差分・エラー行だけを読む。
- マーカー文字列は、導入先の CI レビュー bot・自動コメント bot に合わせて決める。値の置き場は `/review-cycle` の profile（`.claude/skills/review-cycle/references/ci-and-conflict-profile.md` の「CI レビュー bot」節）の 1 か所で、`/handle-review` を単独で呼ぶ場合も同じ値を読む。本書は判定の形だけを定める。調整箇所を 1 か所に限ることで、2 つの skill の判定が食い違わない。

## 2. 違反の退避先の既存性を確認する

「現状の事実のみ」の原則に違反する記述（経緯・時系列・チケット番号の散文混入など）を、退避先へ移すか削除するかを決める手順である。

1. 違反ごとに、`docs/styles/coding_guide/docs.md` の「退避先の判定基準」で推奨する退避先のタイプ（ADR / research / requirements / runbook 等）を判定する。判定基準の表は docs.md が正本であり、ここには再掲しない。
2. 退避先のパスで、既存ドキュメントの有無を `git grep -l <キーワード> origin/main -- '<退避先パス>'` で確認する。ref は `origin/main` に揃える（`docs/harness/skills/shared/sync-prelude.md`）。
3. 結果に応じて `fix_action` を割り当てる。

| 既存の退避先                   | `fix_action`                        | 編集                                                                                                                        |
| ------------------------------ | ----------------------------------- | --------------------------------------------------------------------------------------------------------------------------- |
| あり（内容が既に退避先にある） | `delete`                            | 該当する記述を削除する                                                                                                      |
| あり（参照を残したい）         | `replace_with_link <existing_path>` | 経緯の記述を、既存の退避先へのリンクに置き換える（編集の形は呼び出し側が定める）                                            |
| なし                           | `needs_new_doc <推奨退避先タイプ>`  | 自動編集しない。PR 本文に「起票要候補」として根拠付きで列挙し、人間に委ねる（新規 ADR / research の作成は自動編集の範囲外） |

- `needs_new_doc` だけが残り、編集を伴う検出が 0 件の run は、`docs/harness/skills/shared/sync-prelude.md` の「編集を伴わない所見だけの run」に従い、完了報告に列挙して終了する。
- 将来タスクの申し送りを TODO コメントへ変換する検査（`convert_to_todo`）を持つ呼び出し側は、その判定を先に行い、残りに本手順を適用する。

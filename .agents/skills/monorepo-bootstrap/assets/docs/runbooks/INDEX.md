## エントリポイント（層別の考え方）

## 追加・削除時のチェック

- 新しい runbook を追加したら本 INDEX に追記する。
- runbook を削除・リネームしたら、対象ファイル名でリポジトリ全体を grep して参照元を洗い出し、本 INDEX の行とあわせて再配線する（ADR・Issue 成果物等の凍結アーカイブは書き換えない）。
- 同ディレクトリのファイルは file 名のみで参照し、他ディレクトリへは相対パスで参照する（例: ADR は `../adr/`）。

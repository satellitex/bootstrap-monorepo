## 追加・削除時のチェック

- 新しい runbook は冒頭に `#` 見出しとリード文（対象と用途）を書く。本 INDEX の行は更新主体が起こす（割当表 → `docs/harness/skills/shared/index-writer-policy.md`）。
- 新しい runbook は `README.md` の必須要素を満たす。
- runbook を削除・リネームしたら、対象ファイル名でリポジトリ全体を grep して参照元を洗い出し、再配線する（ADR は決定時点の記録のため書き換えない）。
- 同ディレクトリのファイルは file 名のみで参照し、他ディレクトリへは相対パスで参照する（例: ADR は `../adr/`）。
